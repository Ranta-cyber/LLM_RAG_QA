Hands-on learning and proof-of-concept project
==============================================

In this project I created for an insurance company a little chatbot and QA for it.

Coded with Python using PyCharm so at same time I learned more Python.

I wanted to make it locally and with no costs, so I downloaded llama3.2 model and I used Chroma as database.

The company insurance information and documents are stored in data/documents/insurance_policy.txt.

So the chatbot is created with the company documents and user can ask questions about and got an answer.

RAG/LLM Chatbot
=================

On src/rag.py can see the complete RAG LLM pipeline is called on main.py.

The flow is:

-Read the document data/documents/insurance_policy.txt
-Chunk and embed the data
-Save on vector database (Chroma)
-User ask as question
-RAG find relevant context
-LLM compose answer with using the context (Ollama)

Running: (Install packages, etc. as can see on requirements.txt)

python main.py

User input for example : 'How much compensation I get if I loss my luggage?'

(The answer should be 'Answer: The maximum compensation for lost baggage is 2000 euros.')


QA Testing
==========

I included in the project QA part so can test if context retrieved by RAG is correct and
if answer generated by LLM is correct.

So with Ragas for example, are tested some metrics like faithfulness, distances and contextPrecision.

The tests are made using python.

There are a few test cases on rag_test_cases.json
example:
{

"name": "Baggage compensation",

"question": "How much can I get for my lost luggage?",

"expected_answer": "2000",

"expected_context": "lost baggage",

"should_answer": true

}
The test suite covers:

Deductible
Lost baggage compensation
Medical expenses
Combined questions
Negative test to test hallucination

test_rag.py read and execute those test cases.

Running the tests:

Activate the virtual environment and run:

python -m pytest tests/test_rag.py -v

(The result should be:

tests/test_rag.py::test_rag_answers[Deductible] PASSED

tests/test_rag.py::test_rag_answers[Baggage compensation] PASSED

tests/test_rag.py::test_rag_answers[Medical expenses] PASSED

tests/test_rag.py::test_rag_answers[Unknow alien damage] PASSED

tests/test_rag.py::test_rag_answers[Baggage compensation and deductible] PASSED)
